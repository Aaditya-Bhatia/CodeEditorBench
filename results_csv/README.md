# Results CSV Directory

Generated by `show_result_matrix.py` and `show_results.py` from `benchmark_runs/`.

## Files

### Result Matrix (presentable tables)

| File | Description |
|------|-------------|
| `result_matrix.md` | Main experiment — 5 tables: Debug, Translate, Switch, Polish, Average |
| `result_matrix.csv` | Same data in CSV (all 4 metrics per ablation as columns) |
| `result_matrix_10k.md` | 10K sample experiment — same 5-table format |
| `result_matrix_10k.csv` | Same as above in CSV format |

### Detailed Results (full status + both metric sets)

| File | Description |
|------|-------------|
| `results_primary.csv` | Main experiment — primary metrics, all models, with run status info |
| `results_primary_10k.csv` | 10K experiment — primary metrics |
| `results_plus.csv` | Main experiment — plus metrics (LeetCode-only problems) |
| `results_plus_10k.csv` | 10K experiment — plus metrics |

## Metrics

- **Debug** (`code_debug`): Code debugging pass rate
- **Translate** (`code_translation`): Code translation pass rate
- **Switch** (`code_requirement_switch`): Requirement switching pass rate
- **Polish** (`code_polishment`): Code polishing pass rate

## Ablations

- **Baseline**: Pre-trained model, no fine-tuning
- **Clean / LLM-Cleaning**: Fine-tuned on LLM-cleaned data
- **Dirty / Static-Cleaning**: Fine-tuned on statically-cleaned data
- **Unclean-74K / Unfiltered**: Fine-tuned on unfiltered 74K dataset

## Regenerating

```bash
python show_result_matrix.py   # matrix files
python show_results.py         # detailed CSV files
```
